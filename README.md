# 디지털윤리교육연구회 사이트 (1단계: 정적 사이트)

로그인·서버 없이 HTML 파일만으로 돌아가는 사이트입니다. GitHub Pages에 올리면 바로 공개됩니다.

## 내용 고치기 — `data.js` 하나만

| 바꿀 것 | data.js 안의 이름 |
|---|---|
| 연구회 이름·한 줄 소개·문의 링크 | `site` |
| 학년군·주제 필터 | `grades`, `topics` |
| 이달의 과제 (맨 위 = 진행 중) | `tasks` |
| 자료실 | `resources` (`url`에 드라이브 공유 링크) |
| 연수 일정 (날짜 지나면 자동으로 '돌아보기'로) | `trainings` |
| 시작하기 · 꿀 링크 | `start`, `links` |
| 공지 (`pin: true` = 맨 위 고정) | `notices` |
| 운영진 역할 | `roles` |

- `sample: true`가 붙은 항목은 화면에 **예시** 라벨이 뜹니다. 실제 자료로 바꾸면 그 줄을 지우세요.
- 학생 이름·사진, 교사 연락처는 넣지 않습니다.

## 미리 보기

```bash
python -m http.server 8765
```

브라우저에서 http://localhost:8765 를 엽니다. (`index.html`을 더블클릭해도 열립니다.)

## 파일

- `index.html` 머리·바닥 틀
- `style.css` 디자인 (색은 맨 위 `:root`에서 한꺼번에 바꿈, 다크 모드 포함)
- `app.js` 화면 그리기 (보통은 손댈 필요 없음)
- `data.js` 내용
