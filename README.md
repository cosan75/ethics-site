# 디지털윤리교육연구회 사이트 (1단계: 정적 사이트)

로그인·서버 없이 HTML 파일만으로 돌아가는 사이트입니다. GitHub Pages에 올리면 바로 공개됩니다.

## 내용 고치기 — `data.js` 하나만

| 바꿀 것 | data.js 안의 이름 |
|---|---|
| 연구회 이름·슬로건·회원 수·가입 안내 | `site` (`joinUrl`에 가입 신청 폼 주소를 넣으면 버튼이 생김) |
| 설립 목적·활동 방식·지원 자격 | `purposes`, `ways`, `eligibility` |
| 운영 조직(팀)·권역 | `teams`, `regions` — 이름은 넣지 않음 |
| 자료실 | `resources` (`links`에 `["수업 PPT", "주소"]` 묶음) |
| 학년군·주제 필터 | `grades`, `topics` |
| 프로젝트 (맨 위 = 홈에 크게) | `projects` |
| 지난 성과 | `achievements` |
| 연수·모임 (날짜 지나면 자동으로 '돌아보기') | `trainings` (`date`가 비면 `when` 글자 표시) |
| 시작하기 · 꿀 링크 | `start`, `links` |
| 공지 (`pin: true` = 맨 위 고정) | `notices` |

- 학생 이름·사진, 교사 이름·전화번호는 넣지 않습니다.
- 내용 출처: 「디지털윤리교육연구회 소개자료」(2026), 「2026 연구계획서」, 「2026 디지털 윤리 교육 수업자료 목록(서산교육지원청)」.

## 미리 보기

```bash
python -m http.server 8765
```

브라우저에서 http://localhost:8765 를 엽니다. (`index.html`을 더블클릭해도 열립니다.)

## 파일

- `index.html` 머리·바닥 틀
- `style.css` 디자인 (색은 맨 위 `:root`에서 한꺼번에 바꿈, 다크 모드 포함)
- `app.js` 화면 그리기 (보통은 손댈 필요 없음)
- `data.js` 내용
- `img/logo.png` 연구회 엠블럼 (소개자료에서 추출)
